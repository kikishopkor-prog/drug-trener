# Твой Друг Тренер — проект для Vercel

Готовое приложение на React + Vite + Tailwind. Вся логика — в `src/App.jsx`, картинки и иконки — в папке `public/`.

## Как выложить на Vercel (через GitHub, самый простой путь)

1. Зарегистрируйся на https://github.com и https://vercel.com (можно войти в Vercel через GitHub).
2. На GitHub нажми **New repository**, назови, например, `tvoy-drug-trener`, создай репозиторий.
3. Загрузи в него **содержимое** этой папки: на странице репозитория **Add file → Upload files**, перетащи `index.html`, `package.json`, `vite.config.js`, `.gitignore`, папки `src` и `public`. Нажми **Commit changes**.
   (Папку `node_modules` загружать не нужно — её нет.)
4. В Vercel нажми **Add New → Project**, выбери этот репозиторий, **Import**.
5. Vercel сам определит Vite. Настройки менять не нужно:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
6. Нажми **Deploy**. Через 1–2 минуты получишь адрес вида `https://tvoy-drug-trener.vercel.app`.

Любое следующее изменение файла в GitHub автоматически обновляет сайт.

## Как запустить у себя (по желанию)

Нужен Node.js 18+ (https://nodejs.org).

```bash
npm install
npm run dev      # откроется http://localhost:5173
npm run build    # проверочная сборка в папку dist
```

## Что сделать ПЕРЕД тем, как давать ссылки клиентам

Переключатель «Клиент / Тренер» и кнопка «Показать приветствие и онбординг заново» уже отключены (`DEV_SWITCHER = false` в `src/App.jsx`).

- **Вход для тренера:** `ваш-сайт/#admin`. Сейчас пароль — `change-me`, **обязательно смени его**.
  В `src/App.jsx` найди `const ADMIN_HASH = "…"` и замени значение на SHA-256 нового пароля. Получить его можно в консоли браузера (F12 → Console):
  ```js
  crypto.subtle.digest("SHA-256", new TextEncoder().encode("мой-новый-пароль")).then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2, "0")).join("")))
  ```
  Скопируй получившуюся строку в `ADMIN_HASH`.
- Пароль проверяется прямо в браузере — это защита «от случайных», но не настоящая безопасность.
- **Клиенты** заходят только по своей персональной ссылке (её копируешь в карточке клиента). Без ссылки им показывается экран «Вход по персональной ссылке».

## Важно знать про данные

Сейчас все данные (клиенты, программы, замеры, отметки) хранятся в `localStorage` **в браузере того, кто открыл сайт**. Это значит:

- Клиенты и тренер **не видят данные друг друга**: программа, созданная тобой на твоём телефоне, не появится в телефоне клиента, а отметки клиента не придут к тебе.
- Если очистить данные браузера или открыть сайт на другом устройстве, всё будет пустым.

Для реальной работы с клиентами нужна общая база данных (например, Supabase или Firebase) и вход по паролю/ссылке. Приложение к этому подготовлено (всё состояние лежит в одном объекте), но подключение базы — отдельный этап.

## Структура

```
index.html            страница, иконки, заголовок
package.json          зависимости и команды
vite.config.js        настройки сборки (React + Tailwind)
src/main.jsx          запуск приложения
src/index.css         подключение Tailwind
src/App.jsx           всё приложение (кабинеты клиента и тренера)
public/               фото тренера, иконки, скриншоты для онбординга
```
